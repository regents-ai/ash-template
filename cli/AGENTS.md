# Ash Template commands

`COMMANDS.md` describes every command first; `commands.json` is the same list in the form
the command line reads, whose code lives in `regents-cli`. Change the docs, then the route,
its OpenAPI operation and `commands.json` in one commit, verify with `make check-cli` from
the repository root, then send the change note. `README.md` explains each step and what
does not belong here.
